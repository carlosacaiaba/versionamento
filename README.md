tecnologias utiizada 
• HTML5: Define a estrutura semântica e organização das páginas (menus, tabelas, modais).
• CSS3: Controla o design visual e a responsividade usando Flexbox, CSS Grid e @media queries para ecrãs móveis.
• JavaScript Vanilla (ES6+): Executa toda a lógica do CRUD, controlo do carrinho e manipulação dinâmica do ecrã.
• LocalStorage: Recurso do navegador usado para a persistência de dados (guarda os produtos salvos para não sumirem ao atualizar).
• FontAwesome: Biblioteca externa para carregar os ícones visuais da interface.
